# Ejercicio 1
Para la escena se han creado 5 esferas (3 de color rojo, 2 de color verde). El ejecicio consiste en disparar un evento cuando el cubo colisione con el cilindro, para ello se han creado dos scripts para el notificador y los subcriptores. 
* Notificador: cuando se detecta la colisión dispara el evento 
* Subcriptores: cuando reciben el mensaje una variable booleana se pone a true, lo que activa el movimiento de cada esfera hacia el objetivo asignado.

Las esferas rojas tienen como objetivo alguna esfera verde y las verdes tienen como objetivo el cilindro.
